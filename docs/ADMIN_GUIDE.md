# Инструкция администратора

## Управление сотрудниками

Раздел **Сотрудники** → добавление пользователя с указанием логина, пароля, ФИО, должности и роли.

Роли:
- **Администратор** — полный доступ
- **Фармацевт** — медикаменты, склад, отчёты
- **Кассир** — только касса и история продаж
- **Складской работник** — склад и поставщики

## Резервное копирование

Ежедневно выполняйте дамп базы PostgreSQL (`pg_dump`) или копирование файла `db.sqlite3`.

## Журнал действий

Раздел **Журнал** фиксирует входы, выходы и изменения данных.

## Django Admin

Дополнительная панель: `/admin/` (суперпользователь создаётся командой `createsuperuser`).
